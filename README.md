# FlashMarket — Design inspirado na referência enviada

Página inicial refeita com linguagem visual de e-commerce promocional: cabeçalho escuro, navegação compacta, busca central, ofertas em blocos, banners, categorias e produtos.

## Funcionalidades
- Busca
- Filtros e ordenação
- Categorias
- Favoritos
- Carrinho com quantidades
- Login/cadastro demonstrativo
- Sessão persistente
- Newsletter
- Modais de produto
- Google Maps
- Layout responsivo
- LocalStorage

## Abrir
Abra `index.html` no navegador.

A autenticação e o checkout são demonstrativos no frontend. Para produção, conecte a API/backend, banco de dados e gateway de pagamento.
